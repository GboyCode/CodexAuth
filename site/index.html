GOOD TO KNOW

你可能还想知道。

开始之前，把几个问题说清楚。

在 GitHub 反馈问题
这是 OpenAI 官方工具吗？

不是。CodexAuth Switch 是独立开发的开源项目，与 OpenAI 无官方关联。它用于管理你自己的 Codex App 登录账号，不提供账号或订阅服务。

使用它需要付费吗？

CodexAuth Switch 采用 MIT 许可证，免费开源。Codex / ChatGPT 账号与订阅仍由你自行管理；使用本工具不会增加或绕过账号的官方额度。

Windows 和 macOS 的功能一样吗？

两者均提供账号管理、额度与本地用量查看、凭证迁移。自动切换并继续任务目前面向 Windows。macOS 的原生登录、Keychain 和完整 GUI 流程仍待实机端到端验证，请以仓库说明与版本说明为准。

网站里的面板能操作我的真实账号吗？

不能。这里是使用虚构账号与示例额度的交互预览，不读取本机登录文件。实际账号管理需要下载桌面应用，在你自己的电脑上进行。

用量统计等于官方账号累计吗？

不等于。Token 用量来自本机 Codex 日志，受本地记录与统计范围影响。额度信息会标注数据来源和更新时间，不能将本地统计当作官方账号的完整历史。
