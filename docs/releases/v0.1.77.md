# CodexAuth Switch v0.1.77

修复新版 Windows Codex 中额度耗尽后未触发自动切换、浮窗额度停留在旧快照的问题。

- 兼容新版 `codex-app-tools-*` 本地接口，并保留旧版 `codex-browser-use-*` 接口支持。
- 恢复任务错误监听和当前账号额度刷新；Codex 重启或接口切换后可重新连接。
- 继续核验接口是否提供所需工具，排除仅提供浏览器功能的接口；多个兼容实例并存时仍暂停自动恢复。
- 保留额度耗尽判断、切换前倒计时、任务运行检查和账号校验。

验证：新旧接口发现、浏览器接口排除、重复接口去重、多实例保护、断线重连、自动恢复、倒计时及额度刷新测试通过。本机 Windows 安装后发生一次真实额度耗尽，已成功自动切换并恢复 3 个中断任务；其他设备的实际运行效果仍需安装后确认。
