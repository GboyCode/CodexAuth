# CodexAuth Switch v0.1.37

修复从 GitHub 或面板“检查更新”下载安装后，应用图标拉长、底部被裁切的问题。

- 图标改为在固定像素 Canvas 中渲染，不再截取可能被构建机屏幕高度限制的窗口；保持原有图案与配色。
- 同时覆盖应用、安装器、凭证文件关联和托盘图标的生成，以及 macOS 使用的 PNG 源图。
- 打包时检查 1024px PNG、ICO 全部七种尺寸、像素数据完整性与图案位置；不合格图标会阻止打包。
- Windows 和 macOS 流水线增加 100% / 200% 显示缩放回归，验证图案边缘与中心没有裁切或拉伸。
- 本次仅修复图标及构建流程，不改变账号、凭证、额度或任务恢复逻辑。

安装包：Windows x64、macOS Intel（x64）、macOS Apple Silicon（arm64）。

请使用本版安装包更新；若 Windows 仍显示旧快捷方式图标，可删除旧快捷方式后重新创建。自动任务恢复仍仅支持兼容的 Windows Codex 桌面版。

## English

Fixes stretched and bottom-clipped application icons in the GitHub installers, including downloads opened through the in-app update check. Icons now render to a fixed-size Canvas rather than a display-constrained window capture. Packaging validates PNG/ICO dimensions, complete bitmap data and face placement, while both platform jobs test rendering at 100% and 200% display scale. Account, credential, quota and recovery behavior is unchanged.
