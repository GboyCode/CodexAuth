# CodexAuth Switch v0.1.94 — macOS

- 删除登录时启动下方的常驻说明，仅在系统需要批准或设置失败时显示提示。
- “登录时启动”仅保留在主窗口设置中；菜单栏弹窗设置只显示背景不透明度。
- 弹窗按实际内容及账号数量自动增高、缩短，三账号不再留出固定高度空白；账号较多时限制在屏幕可用范围内，并在账号列表内滚动。宽度继续保持 320pt。
- 关闭按钮、图标收回及点击外部收起时，增加约 120ms 的轻微上移淡出动画。重新展开会取消尚未完成的隐藏，避免快速点击导致窗口意外消失；遵循系统“减少动态效果”。此效果为菜单栏弹窗过渡，并非 Dock 最小化的“神奇效果”。
- 延续隐藏时停止额度刷新、无本地 Token 统计及日志后台扫描的行为。

验证涵盖：0/1/3/多账号布局与列表滚动、账号删除后缩短、设置入口、无常驻登录提示、减少动态效果、远程 Mac 原生窗口自适应高度和跨应用收起、快速重新展开、Windows 浮窗交互回归。

仅发布 macOS Apple Silicon arm64 / Intel x64 安装包。Developer ID 签名及 Apple 公证仍暂缓。
