# CodexAuth Switch v0.1.75

修复新版 Codex 提示额度耗尽后，CodexAuth 未触发自动切换的问题。

- 兼容额度报错中的新链接 `/settings/usage` 和旧链接 `/codex/settings/usage`，在桌面接口省略错误码时仍能识别额度耗尽。
- 保留失败任务、账号校验、其他任务运行检查和可取消倒计时；普通网络错误、工具报错及历史错误不会因此触发切换。
- 补充新格式报错的回归验证，覆盖倒计时、切换、续任务只执行一次以及错误类型排除。

本次正式版也包含 v0.1.72 之后已完成的中英文切换、设置与账号面板精简，以及周额度耗尽时的可选重置卡恢复功能。

验证：本地自动恢复回归通过；此前已将同一逻辑修复打包安装并核验账号和设置保留。Windows 安装包与 Intel / Apple Silicon macOS DMG 由本版本 GitHub Actions 执行项目检查后构建。模拟恢复验证不等同于再次实际耗尽账号额度的端到端验证。
