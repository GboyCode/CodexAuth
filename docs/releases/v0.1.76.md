# CodexAuth Switch v0.1.76

修复 Windows 账号切换被残留 Codex CLI / app-server-daemon 阻止后，桌面关闭且报错乱码的问题。

- 关闭 Codex 桌面前先检查冲突，手动切换显示进程名称、PID 和完整路径。
- 可取消并保留当前账号与窗口，或确认结束列出的进程后继续切换。默认选择取消，关闭提示框也视为取消。
- 结束前再次核对进程路径和启动时间；进程已变化、无法核验或无法结束时停止切换并清楚提示。
- 自动切换遇到冲突只提示，不自动结束独立 CLI / 守护进程。
- 修复 PowerShell 中文输出编码，取消切换后恢复按钮，不误报切换成功。

验证覆盖 Windows 进程归属、孤立守护进程、中文路径、确认与取消、进程编号复用、切换前新增冲突，以及凭证写入保护。另一台电脑的实际升级效果仍需在安装后确认。
