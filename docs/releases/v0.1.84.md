# CodexAuth Switch v0.1.84

修复上下文压缩时额度耗尽，却没有触发自动切换的问题。

- 兼容原生 `Error running remote compact task: ` 前缀；桌面接口省略额度错误码时，仍能识别已知的额度耗尽提示。
- 额度快照尚未更新时，也会进入可取消倒计时，沿用候选账号核验、切换及继续原任务流程。
- 普通压缩失败、网络错误、手动中断、历史失败和已经重新运行的任务不会因此触发切换。

验证：用本机实际失败记录经过已安装 Codex 的错误格式转换后回放；覆盖压缩错误识别、误判防护、倒计时取消、切换及续接去重。未主动耗尽真实账号进行换号测试。
