# CodexAuth Switch v0.1.93 — macOS

- 关闭菜单栏弹窗的系统窗口阴影和 CSS 外层阴影。
- 改为可获取焦点的临时窗口，点击其他窗口、切换到其他应用时自动收起；保留图标开关与 Escape 关闭。
- 弹窗宽度从 360pt 收紧至 320pt，账号容器横向内边距为 6px、账号行横向内边距为 3px，保留操作按钮大小和长名称省略。
- 去掉 Mac 特有的额外白色模糊材质，背景不透明度继续使用 Windows v0.1.88 的同一套 CSS 计算；尊重系统减少透明度和增强对比度设置。
- 主窗口设置及弹窗设置中增加“登录时启动”，使用 macOS 官方 mainAppService 登录项。显示系统实际启用/待批准状态，不覆盖用户在系统设置中关闭的登录项。登录启动只创建菜单栏图标，不打开窗口。
- 隐藏弹窗时移除刷新定时器；保留 60 秒可见额度刷新和手动刷新，不恢复本地 Token 统计及后台日志扫描。

验证包括：原生 Mac 跨应用失焦收起、重新展开、窗口阴影、隐藏后停止刷新；320pt 长账号布局；登录项状态/拒绝/待批准/失败回退；Windows 浮窗回归。原生测试使用隔离的模拟账号，不读取真实凭据。

仅发布 macOS arm64 / x64 安装包。当前未配置 Developer ID 签名及 Apple 公证，登录项在用户系统上的最终启用以 macOS 的实际状态为准；签名、公证及完整性能验收仍属于后续工作。
