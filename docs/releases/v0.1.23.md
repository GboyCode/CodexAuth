# CodexAuth Switch v0.1.23

- 新增可选的“额度耗尽后自动切换并继续”：检测本地任务的额度耗尽错误，按套餐优先级选择账号，重启并核验额度后向原任务发送继续指令，支持批量恢复。此功能目前仅支持 Windows，默认关闭。
- 自动恢复的长说明改为感叹号悬浮提示，保留简短运行状态。
- 每次自动切换前在浮窗旁显示目标账号与 15 秒倒计时，可点“取消本次”、关闭或按 Esc 取消。
- 取消记录持久保存，同一次中断不再重试；新的中断仍按 Plus、五小时 Business、仅周额度 Business 的顺序选择账号。
- 倒计时后重新检查账号和任务状态；窗口异常、休眠或关闭自动开关均阻止切换。
- 包含近期的账号迁移更新：可选择导出当前或全部账号；导入先选文件再输入共用密码，支持最多 100 个文件、密码重试和失败回滚。
- 修复 Windows 凭证文件关联图标及安装后的刷新顺序。
- 提供 Windows x64 安装器、macOS Intel x64 与 Apple Silicon arm64 DMG；macOS 保留账号管理、手动切换和凭证迁移功能。
- 已验证模拟恢复与倒计时取消流程；真实额度耗尽后的切换与原任务续跑仍未端到端实测。
