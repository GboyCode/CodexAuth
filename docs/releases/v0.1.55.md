# CodexAuth Switch v0.1.55

- 修复从团队账号切换到 Plus 后继续原会话，五小时和每周额度可能停留在旧快照的问题。Windows 现在约每 30 秒通过 Codex 桌面本地接口读取当前账号额度，并校验账号、套餐和切换边界。
- 自动切换前后保存桌面接口核验的额度，避免耗尽账号切走后仍显示旧余额。后台读取不阻塞界面；接口不可用时保留快照时间，并使用可用的本地日志。
- 浮窗“主窗口”和“重启 Codex”按钮由 32px 加高到 36px，避免操作区被纵向压缩。
- 取消浮窗顶部置顶、设置和隐藏按钮的白色鼠标跟随描边，保留背景反馈和键盘焦点提示。

额度读取由 Codex 桌面处理相关服务请求，CodexAuth 不直接使用令牌请求远程额度接口。macOS 继续使用本地日志读取额度。

验证：额度读取、账号隔离、切换竞态、自动恢复、账号安全和玻璃动效检查通过；Windows 安装版已覆盖安装并验证实际额度刷新与按钮显示。
