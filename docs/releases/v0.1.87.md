# CodexAuth Switch v0.1.87

修复自动设置 Codex 文件凭证时，对合法 TOML 写法识别不完整的问题。

- 支持裸键、单引号键、双引号键及 Unicode 转义键，避免重复插入同名配置导致 Codex 无法读取配置。
- 正确区分配置与多行字符串、数组中的文本，避免误改开发者提示词或遗漏真正的顶层凭证设置。
- 只替换目标配置值，保留其他设置、注释、BOM 和换行；无法安全确定字符串或容器边界时停止修改。
- 继续使用官方支持的 `cli_auth_credentials_store = "file"`，沿用修改前备份及原子写入流程。

验证覆盖：带引号及转义键、多行基本/字面量字符串、嵌套容器、注释、表作用域、重复设置、幂等性及配置备份写入。
