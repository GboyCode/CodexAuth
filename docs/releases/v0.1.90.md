# CodexAuth Switch v0.1.90 — macOS

修正 v0.1.89 对 macOS 功能范围的处理：保留账号管理、切换和剩余额度查看，仅移除「本地用量」统计区域。

- 恢复当前账号额度、账号列表额度摘要、额度详情和全部账号额度总览。
- 菜单栏面板显示每个账号的会话及周剩余额度，继续使用固定位置的弹出面板和单色图标。
- 移除 macOS 的本地总 Token、输入/输出 Token、会话数、本次/本机全部范围及统计详情，不再执行全量 Token 汇总。
- 不启动空闲时的日志监听和定时扫描；查看额度时复用 60 秒缓存，手动刷新可立即更新。优先读取 SQLite 中的近期额度快照，无快照时最多读取最近 5 个会话文件，不执行额度估算训练。
- 备用账号保留手动在线额度查询，保留账号身份核验和原有查询保护。

本次只发布 macOS Intel x64 与 Apple Silicon arm64 安装包。Windows 功能保持原样，不构建 Windows 安装包；Windows 用户继续使用 v0.1.89。

验证覆盖：macOS 额度读取与缓存、手动刷新、账号隔离、有限会话回退、本地统计禁用、主界面与菜单栏面板交互。原生菜单栏和真实账号切换仍需实机验证。
