# CodexAuth Switch v0.1.95 — macOS

- 以 macOS Accessory 辅助应用模式运行，保留菜单栏图标，不在 Dock 显示运行图标和小圆点。
- 应用包声明 LSUIElement，避免启动时短暂出现 Dock 图标；主窗口仍可从菜单栏打开并取得焦点，打开主窗口不会恢复 Dock 图标。
- 主窗口设置中的“切换后重启 Codex”缩短为“切换后重启”。Windows 文字不变。
- 延续账号数量自适应高度、收起动画、登录时启动和隐藏时停止额度刷新。

验证：启动平台隔离、Mac 原生 Dock 隐藏、主窗口焦点及跨应用弹窗收起/重新展开、安装包 LSUIElement 检查。

仅发布 macOS arm64 / x64 安装包，Developer ID 签名与 Apple 公证仍暂缓。
