## 更新内容

- 注册 `.codexauth` 加密凭证文件类型，使用 CodexAuth 应用图标，替代系统空白文件图标。
- 安装更新后对已有和新导出的凭证文件生效，无需重新导出。导入仍通过主窗口的“导入凭证文件”完成。

## English

Register the `.codexauth` encrypted credential file type with the CodexAuth app icon. Existing exported files do not need to be exported again. Import files using Import credentials in the main window.

Windows x64 and macOS Intel / Apple Silicon installers are supported. Installers are unsigned; macOS builds are not notarized.
