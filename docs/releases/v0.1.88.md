# CodexAuth Switch v0.1.88

适配 Codex 26.1103 的账号独立项目状态，修复切换账号后项目列表为空、会话只出现在“最近”的问题。本次正式发布同时包含 v0.1.85 至 v0.1.87 的额度查询、订阅到期日和配置兼容改进。

## 切换账号保留本地项目

- 手动切换和自动切换共用保护流程：退出 Codex 后，将本地项目和会话归属合并到目标账号的本地状态，再更换凭证。
- 保留目标账号已有项目，并同步本地项目排序、折叠状态和本地项目迁移信息。不同用户即使处在同一个 Business 工作区，也分别识别。
- 仅复制本地项目元数据；不复制其他账号的云端内容、身份设置、提示草稿、权限授予或待发送消息。
- 修改前加密备份项目状态，保留最近 5 份。状态损坏、格式不兼容、账号无法确认、备份失败或发现并发改写时，停止切换。
- 已有自动切换开关保持原值。

## 额度与订阅信息

- 只读额度请求遇到短暂网络故障或桌面接口繁忙时自动重试一次，失败时保留上次结果，并显示失败原因和时间；继续遵守服务端限流要求。
- 独立获取并保存订阅到期日期，首次补齐记录后复用缓存，在到期前后重新核验，避免长期显示“待更新”。
- 订阅查询失败保留已有日期，不影响额度结果，也不会额外续期凭证或切换账号。

## 配置兼容

- 支持 Codex TOML 配置中的带引号及转义键、多行字符串和嵌套容器，避免重复插入凭证配置或误改提示词。
- 保留其他配置、注释及原有格式，继续在修改前备份；无法安全解析时停止修改。

验证覆盖：新版 Codex 启动及账号状态选择、首次和往返切换、项目合并、同工作区不同用户、旧版兼容、并发改写、失败保护，以及额度、订阅和配置兼容回归。
