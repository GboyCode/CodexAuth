# CodexAuth Switch v0.1.46

- 主面板、用量页、额度浮窗和自动切换倒计时统一为黑白灰配色：石墨黑渐变、白色卡片、细边框与柔和阴影。参考 [shadcn/ui](https://ui.shadcn.com/) 的简洁层级。
- 加入轻按反馈、分段标签切换、详情与弹窗淡入、额度条平滑过渡；策略开关改为滑动开关。
- 动效只在交互时触发，遵循系统“减少动态效果”设置。
- 预估额度采用灰色纹理条，保留文字说明；删除等危险操作保留红色提示。
- 调整窄窗口下的账号操作布局，保留浮窗“产品名 → 账号 → 版本号”的层级。

## English

A unified graphite-and-white theme for the account panel, usage dashboard, quota widget and recovery countdown. Subtle interaction feedback, switch transitions and dialog entrances respect the system's reduced-motion preference. Estimated quota remains distinguishable through a textured meter, and destructive actions retain their warning color.
