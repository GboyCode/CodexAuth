# CodexAuth Switch v0.1.89

macOS 版聚焦账号切换，并适配 macOS 26 Tahoe 的应用图标和顶部菜单栏交互。

## macOS 账号切换

- 移除用量页、账号额度展示和相关设置，停止后台用量扫描、额度与订阅轮询。
- 保留账号添加、重新登录、手动切换、重命名、删除及加密凭证导入导出。
- 点击顶部菜单栏图标，在图标下方打开固定位置的账号切换面板；点击外部、再次点击图标或按 Esc 收起。
- 菜单栏面板显示当前登录和已保存账号，不再创建可拖动的桌面浮窗。右键菜单仍可打开主窗口、设置开机启动及退出应用。

## 图标

- 从原始 SVG 生成 Tahoe 原生 `.icon` 资源，由系统处理背景和圆角，避免旧图标被再次套框后缩小；同时打包旧版 macOS 使用的 ICNS 资源。
- 顶部菜单栏使用无背景的单色模板图标，提供普通与 Retina 尺寸，由系统适配菜单栏外观。

## 开发与验证

- 新增 `npm run preview:mac`：可在 Windows 上打开 macOS 界面调试预览，使用隔离的模拟账号，不读写真实登录。
- 覆盖 macOS 停止统计任务、菜单栏面板定位与收起、账号界面交互、100% / 200% 图标缩放，以及账号切换安全回归。
- Windows 的用量、额度、桌面浮窗和自动切换功能保持原有行为。

安装包包括 Windows x64、macOS Intel x64 和 Apple Silicon arm64。macOS 原生 Dock 外观、菜单栏交互及真实账号切换仍需实机验证；跨平台界面预览不代替这些验证。
