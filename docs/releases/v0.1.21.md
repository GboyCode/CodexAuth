# CodexAuth Switch v0.1.21

- 新增“额度耗尽后自动切换并继续任务”开关，默认关闭，目前支持 Windows。
- 优先剩余额度最高的可用账号，同额度优先下次重置更早的账号。
- 识别明确额度失败，等待其他任务结束，再切换、重启并在原任务内继续。
- 加入新账号校验、重复恢复保护、失败原因展示和已耗尽账号的 30 分钟冷却。
- 允许已过重置时间的历史快照作为预计额度候选；切换后核验实际额度，不可用则尝试下一个账号。
- 不自动消耗重置次数；普通限流、手动中止、网络及工具错误不会触发。

需要保持 CodexAuth 运行和 Codex 任务窗口可用。桌面本地接口随官方版本变化可能不兼容，此时暂停并显示原因。已验证只读接口和模拟恢复流程，尚未实测真实额度耗尽后的账号切换。
