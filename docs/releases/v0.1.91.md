# CodexAuth Switch v0.1.91 — macOS

修复 macOS 应用图标左侧轮廓和表情缺失的问题。

- 保留原始 SVG，通过 Chromium 在 1024×1024 原生尺寸生成透明无损图层，再交给 Apple Icon Composer 编译，避免直接编译 SVG 时丢失路径。
- 保留 Tahoe 原生图标背景、完整轮廓和清晰表情；菜单栏继续使用单色模板图标。
- 打包时从实际 `.app` 导出 Finder 图标及 ICNS 图像，检查轮廓和左右眼、嘴部，缺损时阻止发布；编译预览存入构建产物以便核对。
- 延续 v0.1.90：保留账号管理、切换和剩余额度查看，仅移除 macOS 本地 Token 用量统计和对应后台扫描。

本次仅发布 macOS Intel x64 与 Apple Silicon arm64 安装包，不构建 Windows 安装包。
