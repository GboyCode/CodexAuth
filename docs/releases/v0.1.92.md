# CodexAuth Switch v0.1.92 — macOS

恢复菜单栏弹窗与 Windows 浮窗一致的设计，并放大菜单栏单色图标。

- 菜单栏弹窗直接复用原有浮窗页面、主题和玻璃样式，恢复当前账号、会话及每周额度进度条、主窗口与重启按钮、快捷切换、重登和账号额度详情。
- 弹窗固定显示在菜单栏图标下，保留透明度设置，使用 macOS 原生背景模糊；隐藏桌面钉住、拖动、缩放和贴边控件，点击外部或关闭按钮可收起。
- 单色模板图标调整为 20pt / Retina 40px，并收紧 SVG 留白；实际图形填充至少 80% 画布，同时保留防裁切余量。
- 保持 macOS 额度缓存及 60 秒可见刷新，隐藏面板时不轮询，手动刷新立即更新；不恢复本地 Token 统计和后台日志扫描。

验证：Mac 弹窗额度、切换、重登、透明度设置、额度详情、隐藏时停止刷新；Windows 原有浮窗交互回归；单色图标的 1x/2x 尺寸、完整边缘和透明表情。

仅构建和发布 macOS Apple Silicon arm64 与 Intel x64 安装包。
