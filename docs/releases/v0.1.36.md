# CodexAuth Switch v0.1.36

本次公开版本汇总 v0.1.26–v0.1.36 的更新：直接登录添加账号、更可靠的额度中断恢复、更快的本地用量读取，以及凭证操作保护。

## 新增与改进

- **直接登录并添加账号**：在账号面板打开官方浏览器登录，完成后自动加密导入，无需退出当前 Codex。支持取消、重新打开和五分钟超时；重复账号更新已有记录，当前账号保留正在使用的凭证。对应 [Issue #1](https://github.com/GboyCode/CodexAuth/issues/1)。
- **额度耗尽后自动切换并继续（可选，Windows）**：兼容 Plus 与 Business 的原生耗尽提示，不依赖浮窗预估归零。可恢复多个符合条件的任务及目标；恢复通过向原任务发送可见的继续指令完成，目标预算和用量计数保持不变。
- **候选账号更合理**：优先 Plus → 有五小时限制的 Business → 仅周额度 Business；同类优先余额高、重置早。尚未重置且任一窗口剩余不超过 2% 的账号会跳过；有记录候选不可用后，才尝试无记录 Business。切换后核验实际账号与额度，全部不可用时停止尝试。
- **紧凑提醒和任务跳转**：浮窗旁的小卡片保留 15 秒倒计时、取消按钮及 Esc 取消；确认恢复后打开首个任务一次，跳转失败不影响续任务。
- **本地用量读取提速与修正**：增长日志增量读取，并发刷新合并；修正独立会话误去重、项目归属及统计范围切换时旧响应覆盖。区分“本次本地”和“全部本地”，无法归属的数据显示未知；本地合计不等于官方账号累计 Token。
- **账号与恢复保护**：先停止桌面及所属 app-server，再保存最终凭证、加密备份和切换；其他仍运行的 Codex CLI 会阻止覆盖。手动账号操作取消待恢复批次；不确定的继续请求不自动重发，较旧的导入凭证会警告并要求重新登录。
- **面板细节**：账号额度总览新增隐藏邮箱按钮；侧栏新增 GitHub 图标、实际版本号、检查更新和开发者微信二维码入口。

## 验证与范围

- 发布前审阅全部 24 个变更源码/测试文件及相关凭证、平台调用，未发现确认的安全漏洞。审计不等于零缺陷或账号风控保证。
- 本地 12 项发布检查通过，覆盖语法、平台、配置兼容、用量、缓存、启动、凭证迁移、更新、自动恢复/目标、隔离登录和账号安全；Windows/macOS 发布流水线均加入新增登录与安全检查。
- 回归使用临时目录、虚构凭证及模拟接口；本次审核未切换真实账号、重启官方 Codex 或耗尽真实额度。真实用户登录授权和 macOS 原生登录/Keychain/GUI 未端到端验证。
- 新增登录使用独立临时目录；官方程序暂存的明文凭证在导入后清理，保存的快照使用 DPAPI / Keychain 加密。已有配置可能按既有兼容逻辑设置文件凭证模式并先行备份。

## English

This release consolidates v0.1.26–v0.1.36: official browser sign-in without logging out of the active account, safer Windows quota recovery and Business fallback selection, compact cancellable reminders, faster incremental local usage reads, credential/race protection, email hiding, and sidebar project/update/contact links.

Local totals are not official lifetime account totals. Recovery sends a visible continuation to the original task and never blindly retries uncertain sends. Native macOS sign-in and real OAuth completion remain unverified; automatic task recovery is Windows-only. All 12 local release checks passed, and both build jobs run the new login and account-safety suites.
