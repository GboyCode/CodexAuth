# CodexAuth Switch v0.1.71

- Windows 当前账号通过 Codex 读取在线额度；备用账号定期在线查询并按需续期。自动切换前重新核验实际额度，查询失败保留旧快照，失败退避和账号隔离继续有效。
- 全部账号额度总览新增“刷新全部”，逐个查询并显示进度、成功数量和失败原因，单个账号失败不影响其他账号。
- 连续在线额度快照用于校准两次查询之间的本地预估，按账号、模型、服务档和额度池隔离样本；预估明确标记，自动切换仍依据实际额度。
- 重置次数右侧显示本地登录快照中的订阅到期日，悬停可查看完整日期。此日期不代表实时续费或扣费日；缺失显示“到期 未知”，快照日期已过显示“到期 待更新”。
- 浮窗钉住后同时置顶并锁定位置，禁止窗口拖动、边缘调整和贴边收起；取消钉住恢复操作。图钉增加倾斜与转正切换效果。
- 压缩浮窗额度页脚和账号列表底部留白，改善账号额度弹层与排序拖动的交互。额度来源统一使用在线／本地口径。
- 移除“会提前用完”“消耗速度正常／宽松”等评价，保留额度比例、重置时间和预估标记。
- 到达额度重置时间后重新读取最新额度和下一次重置时间；没有额度记录或重置时间的账号保留受控重试与切换后核验。

验证：语法检查、本地用量与额度读取、在线凭据续期与失败退避、账号切换安全、额度校准、订阅日期及自动恢复回归通过；Windows Electron 浮窗交互和 860／1040／1280 宽度的总览布局验证通过。未通过耗尽真实账号触发完整自动切换。跨平台安装包由本版本 GitHub Actions 构建。
