# CodexAuth Switch v0.1.25

- “额度耗尽后自动切换并继续”支持目标模式，可识别 Codex 的 `usageLimited` 状态并批量恢复。
- 沿用账号优先级、15 秒倒计时与取消功能，恢复原目标并保留预算、累计 token 和用时。
- 手动暂停、阻塞、目标预算用完、已完成或开启前的历史中断不会自动恢复；其他活跃目标会阻止重启。
- 恢复后同时确认新轮次与原目标状态；结果不确定时提示检查，不重复发送。

自动恢复目前仅支持兼容的 Windows Codex 桌面版。macOS 保留原有账号管理功能。

已验证模拟恢复与本机 Codex 隔离目标接口；真实额度耗尽后的换号、重启和目标持续推进仍未端到端实测。
