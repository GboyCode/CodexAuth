# 平台发布

| 平台 | 发布分支 | 标签示例 | GitHub Latest |
| --- | --- | --- | --- |
| Windows | `windows` | `0.1.89` | 是，兼容已安装的 Windows 客户端 |
| macOS | `macos` | `macos-v0.1.97` | 否 |

在对应分支更新 `package.json` 和锁文件的版本，在 `docs/releases/<完整标签>.md` 写发布说明。先推送分支，再推送标签。工作流检查版本及提交所属分支，只构建目标平台。

两个平台可以使用相同的数字版本。Windows 使用纯数字标签，以便 0.1.88 客户端能解析版本号，并避免与历史 `v*` 标签冲突。macOS 0.1.97 开始按 `macos-v*` 标签和当前架构的 DMG 检查更新。
